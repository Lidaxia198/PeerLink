# Screenshots

本目录为 README 使用的**真机截图**（已统一为英文文件名，便于 GitHub 正常显示）。

## 文件对照

| 文件 | 界面 / 功能 |
|------|-------------|
| `01-home.png` | 首页：选 Wi‑Fi / 蓝牙，创建或加入房间 |
| `02-create-room.png` | 创建房间弹窗：密钥创建 / 直接创建 / 取消 |
| `03-host-with-key.png` | 主机等待：展示 6 位房间密钥 + 本机 IP / 端口 |
| `04-host-open.png` | 主机等待：无密钥房间，对方可直接加入 |
| `05-connected.png` | 已连接：开始投屏、发送文件、接收目录 |
| `06-cast-settings.png` | 投屏设置：流畅 / 均衡 / 高清 |
| `07-pip-window.png` | 收屏悬浮小窗 + 画面显示（填充 / 适应 / 镜像 / 快门） |
| `08-pip-bubble.png` | 小窗收起后的边缘气泡 |
| `09-cast-sharing.png` | 发送端系统「屏幕共享中」状态 |

## 替换说明

用新截图覆盖同名文件即可；推送后 GitHub README 预览会自动更新。建议竖屏、长边 ≤ 1600px。
